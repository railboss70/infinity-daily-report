# Infinity Daily Report

Single-file web app for Infinity Track daily reports and weekly billing (subcontractor for STX Corporation).

## How to use
1. Download `index.html` (once uploaded)
2. Open it in any modern browser, or Add to Home Screen on a phone so it behaves like an app
3. All data (rates, crew, dailies, etc.) is saved only on the device — nothing is sent to a server

## Making it live (optional)
In the repo Settings → Pages, set Source to Deploy from branch `main` / root. GitHub will give you a public URL.

You can change the repo from public to private at any time under Settings → General → Danger Zone.
